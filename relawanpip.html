Belum ada akun terdaftar.

Akun Anda tercatat sebagai relawan, jadi hanya bisa melihat data. Untuk akses penuh, jadikan diri Anda admin dengan salah satu cara:

  1. Cara cepat: klik tombol “Jadikan Saya Admin” di kartu atas — syaratnya aturan Firestore mengizinkannya (lihat di bawah).
  2. Cara aman: Firebase Console → Firestore Database → koleksi users → dokumen dengan ID UID Anda → ubah field role menjadi admin, lalu klik Muat Ulang.

Aturan Firestore agar tombol cepat berfungsi:

match /users/{uid} {
  allow update: if request.auth.uid == uid;
}
